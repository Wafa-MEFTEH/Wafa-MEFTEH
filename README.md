# Academic site

Static site, no build step. Edit the HTML files in any text editor.

## Edit
- Replace "Your Name", the email, and every placeholder.
- Put your CV at assets/cv.pdf and course files in courses/.

## Publish for free with GitHub Pages
1. Create a free account at github.com.
2. Create a public repository named YOURUSERNAME.github.io
3. Upload all files of this folder (Add file > Upload files), then commit.
4. In the repository: Settings > Pages > Build and deployment > Deploy from a branch > main, folder / (root).
5. After a minute the site is live at https://YOURUSERNAME.github.io

Free alternatives: Cloudflare Pages, Netlify.
